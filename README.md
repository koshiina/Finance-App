Gana paprastas projektas pagal tutorialą, tiesiog susipažinti su ASP.NET Core, su MVC bei Web aplikacijų kūrimų.
Paleidus programą, atsidaro web puslapis. Parašius Finance atidaro puslapį su išlaidų lentele, į kurią kitame puslapyje galima pridėti išlaidų sumą, kategoriją bei apibūdinimą. Įvedus duomenis apačioje po lentele yra matoma pie diagrama su išlaidomis pagal kategoriją.
